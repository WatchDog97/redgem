# Redgem

Подсказка ответов на тренировочные тесты. База — 1793 вопроса, зашита внутрь.
Интернет не нужен, ставить ничего не надо, права администратора не требуются.

Скачать: [**Releases**](../../releases/latest)

## Windows

| файл | что это |
|---|---|
| `Redgem.exe` | 9,3 МБ, работает поверх любой программы |

Двойной клик — программа уходит в фон. Сделайте так, чтобы вопрос был виден
на экране, и нажмите **Alt+X**. Рядом с правильным ответом появится точка.

Распознавание встроено в саму Windows, ставить нечего.

Запасная клавиша: **Alt+Пробел**. Перезапуск: **Ctrl+Z**. Выход — значок у часов.
Проверка готовности: `Redgem.exe --check`

## Linux / RedOS

| файл | что это |
|---|---|
| `Redgem-browser-linux.run` | 170 МБ, **один файл на всё**: браузер + распознавание + база |
| `Redgem-linux.pyz` | 8,3 МБ, только распознавание экрана |
| `redgem.sh` | запускалка для `.pyz` с проверкой пакетов |

```sh
chmod +x Redgem-browser-linux.run
./Redgem-browser-linux.run
```

Откроется браузер сразу на сайте с тестами. Нажмите **Q** на странице теста —
правильные варианты отметятся сами.

Тот же файл умеет и остальное:

```sh
./Redgem-browser-linux.run --ответы     только распознавание экрана, без браузера
./Redgem-browser-linux.run --проверка   чего не хватает в системе
./Redgem-browser-linux.run --помощь     подсказка
```

Браузеру ничего не нужно — он несёт свои библиотеки. Распознаванию экрана нужны:

```sh
sudo dnf install python3 python3-tkinter tesseract ImageMagick
```

Русский язык распознавания **ставить не надо** — он едет внутри программы.
На установочном диске RedOS 8 его и нет: из 3513 пакетов там только английский.

Для **Alt+X** сеанс должен быть **X11, а не Wayland** — в Wayland перехватить
глобальную клавишу нельзя. Проверить: `echo $XDG_SESSION_TYPE`, сменить —
шестерёнкой на экране входа. Браузеру это не мешает: там клавишу ловит страница.

Распаковывается в `~/.th-browser` (≈390 МБ), удаляется через `rm -rf ~/.th-browser`.
Другое место: `TH_DIR=/путь ./Redgem-browser-linux.run`

**Флешку можно вынимать** сразу после запуска — и браузер, и программа уже
в домашней папке. Нельзя только во время первой распаковки.

## Свой браузер

`redgem-tampermonkey.user.js` — поставьте расширение Tampermonkey и откройте
этот файл. Клавиша та же: **Q**.

## Если ответ не находится

Значит этого вопроса нет в базе или он сформулирован иначе. Redgem никогда
не отмечает вариант наугад — лучше промолчать, чем подсказать неверно.

Из 2453 заданий в исходных документах в базу не попали 112: 89 на соответствие
(верный ответ там не размечен вовсе), 21 с одними неверными вариантами,
2 с пустым текстом.
